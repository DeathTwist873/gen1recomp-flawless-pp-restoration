# Flawless PP Restoration (Gen1Recomp Mod)

A Quality-of-Life mod for **Gen1Recomp** that rewards tactical, zero-damage battle play by restoring Power Points (PP) upon winning fights without taking damage.

## Features
- **Flawless Victory Detection:** Automatically tracks if your active Pokémon finishes a battle without receiving damage.
- **PP Recovery:** Restores move PP upon securing a clean win, keeping your team fresh during long routes or wild grinding sessions.
- **In-Game Notifications:** Displays clear battle messages when a flawless recovery is triggered.

## Installation
1. Download or clone this repository.
2. Copy the mod folder into your Gen1Recomp `mods/` directory:
   ```text
   Gen1Recomp/mods/gen1recomp-flawless-pp-restoration/
   ```
   Launch the game and enjoy!
